# Asset Import Checklist — Protocol: Hex0

## 1) Dosya Teslim Kontrolü
- [ ] Tüm dosyalar PNG ve şeffaf arka plan
- [ ] Dosya adları `AI_ASSET_PROMPTS.md` ile birebir uyumlu
- [ ] Tüm zorunlu klasörlere dosyalar yerleştirildi (`assets/...`)

## 2) Görsel Kalite Kontrolü
- [ ] Hero ve enemy küçük ölçekte okunabilir
- [ ] Enemy basic ve elite birbirinden anında ayrışıyor
- [ ] XP small/medium/large tek aile ama farklı değer hissi veriyor
- [ ] Projectile türleri savaşta birbirine karışmıyor
- [ ] UI ikonlar 24-32px ölçekte net

## 3) Stil Tutarlılığı
- [ ] Sci-fi stylized dil tüm assetlerde aynı
- [ ] Rarity renk mantığı korunuyor (common→legendary)
- [ ] Aşırı detay/photoreal öğe yok

## 4) Godot İçe Aktarım
- [ ] Import sonrası sıkıştırma/artifact problemi yok
- [ ] UI paneller 9-slice için uygun kenar yapısına sahip
- [ ] Bar fill/frame çiftleri doğru görünüyor
- [ ] VFX ring sprite’larında kenar kırılması yok

## 5) Oyun İçi Kontrol
- [ ] HUD okunabilirliği bozulmadı
- [ ] Level up panel butonları net okunuyor
- [ ] Perk tree node görselleri kalabalıkta dahi anlaşılır
- [ ] Çatışmada mermi ve düşman ayrımı rahat
